# Nuclear Decay Simulation

Python simulations of radioactive decay 
for nuclear physics applications.

## Description
This project simulates the radioactive decay 
of various elements using NumPy and Matplotlib.

## Simulations
- **Decay Simulation** : Theoretical decay curve 
  of Iodine-131 with experimental noise 
- **Decay Comparison** : Comparison of decay curves
  for Iodine-131, Barium-140 and Cerium-141
 (For both there is a version with the curve animated) 

## Requirements
- Python 3.x
- NumPy
- Matplotlib
